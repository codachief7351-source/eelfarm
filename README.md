# 장어 양식 대시보드

`index.html` 파일을 크롬에서 열면 바로 사용할 수 있습니다 (설치 불필요, 인터넷 없이 동작).

## 기능
1. **사육현황** – 수조별 마리수·평균체중 입력 → 총 마리수/총중량 자동 합계
2. **사료 재고·주문 알림** – 실사재고 + 입고량 − 1일 사용량으로 현재 재고 추정, 배송일(영업일)·안전일수를 고려한 주문 권장일과 권장 주문량 표시
3. **휴일 알림** – 2주 내 휴일 미리 알림, 휴일·일요일을 빼고 배송일 계산 (거래처 휴무일 추가 가능)
4. **1일 급이량·어드바이스** – 체중·수온 기준 자동 급이율(직접 입력 가능), 수질값(수온·DO·pH·암모니아·아질산) 기반 조언

## 참고
- 데이터는 브라우저(localStorage)에 저장됩니다. 다른 PC로 옮기거나 보관하려면 **백업 저장 / 백업 불러오기**를 쓰세요.
- 처음 들어있는 수조·사료 값은 **예시**입니다. 실제 값으로 바꿔 입력하세요.
- 🔔 버튼으로 브라우저 알림을 켜면, 페이지를 열 때 주문·휴일 알림이 팝업으로도 뜹니다.
